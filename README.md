# Adjaster.uz — лендинг услуг европротокола

Next.js 16 + Tailwind v4 + shadcn/ui. Весь контент и SEO лежат в одном файле —
`src/lib/site.config.ts`.

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Сайт поднимается на **http://localhost:4000** — порт задан в `package.json`
(`next dev --port 4000`, `next start --port 4000`).

Сборка: `npm run build`, проверка кода: `npm run lint`.

## Структура страницы

1. **Хедер** — логотип, разделы, телефон и кнопка Telegram.
2. **Первый экран** — заголовок, короткое описание, крупный номер телефона и Telegram рядом.
3. **Преимущества** — три карточки, почему выбирают именно вас (`site.advantages`).
4. **Как оформить европротокол** — видео с YouTube и пошаговая инструкция ниже (`site.howTo`).
5. **Стоимость** — цена, что входит, что оплачивается отдельно, кнопка звонка и карта Яндекса с адресом офиса (`site.pricing`, `site.address.map`).
6. **Футер** — короткий текст о компании и контакты: телефоны, Telegram, email, адрес, часы работы.

## Что обязательно поменять

| Где | Что |
|---|---|
| `src/lib/site.config.ts` → `pricing.price` | **Цена 250 000 сум — плейсхолдер.** Поставьте свою. |
| `src/lib/site.config.ts` → `howTo.videoId` | ID ролика с YouTube — часть адреса после `v=`. Пока пусто, вместо видео стоит заглушка. |
| `src/lib/site.config.ts` → `contacts`, `address` | Телефоны, Telegram, email и адреса взяты из открытых источников — сверьте. |
| `.env.local` → `NEXT_PUBLIC_SITE_URL` | Боевой домен. От него зависят canonical, sitemap и микроразметка. |
| `src/lib/site.config.ts` → `address.coords` | **Координаты приблизительные.** Уточните в Яндекс Картах: правый клик по метке → «Что здесь?». Они идут в микроразметку `LocalBusiness`. |
| `src/lib/site.config.ts` → `address.map` | Виджет Яндекс Карт. Сейчас карточка организации `adjaster_uz/121345169480`. Запасной вариант по адресу — в комментарии рядом. |
| `.env.local` → `NEXT_PUBLIC_YM_ID` | Яндекс Метрика. Пусто — скрипт не подключается. |

Логотип лежит в `public/logo.png`. В подвале он выводится белым через CSS-фильтр.
Цвета — в `src/app/globals.css`, блок `:root`: `--tile` (синий бренда), `--tile-deep` (тёмный фон),
`--accent` (оранжевый для кнопок действия).

## Скорость

- Все страницы пререндерятся статически: сервер отдаёт готовый HTML, React догружается следом.
- Шрифты — через `next/font`, файлы лежат на своём домене, запросов к Google Fonts нет.
- Сторонних скриптов на странице нет. Яндекс Метрика подключается только если задан
  `NEXT_PUBLIC_YM_ID`, и грузится после отрисовки (`strategy="afterInteractive"`).
- Видео с YouTube грузится по клику, карта Яндекса — отложенно (`loading="lazy"`).
  До взаимодействия ни один внешний iframe не запрашивается.
- `@vercel/speed-insights` подключён в `src/app/layout.tsx`. Он не ускоряет сайт сам по себе —
  он собирает Core Web Vitals (LCP, CLS, INP, TTFB) у реальных посетителей, чтобы видеть,
  что чинить. Данные появляются во вкладке Speed Insights проекта **после деплоя на Vercel**;
  локально компонент работает в отладочном режиме и ничего не отправляет.

## Что сделано для поиска

- Уникальные title и description на каждой странице, canonical, Open Graph, генерируемая картинка
  `/opengraph-image` с телефоном.
- Микроразметка одним `@graph`: `LocalBusiness` + `AutomotiveBusiness` с адресом, координатами,
  круглосуточным графиком и телефоном; `Service` с ценой; `HowTo` с восемью шагами инструкции;
  `VideoObject` (появляется, как только задан `videoId`); `BreadcrumbList`.
- **Страницы районов** `/rayon/[district]` — по одной на каждый район из `site.districts`,
  со своим H1, title, description, уникальным текстом, ориентирами и координатами.
  Закрывают запросы вида «европротокол + район». Ссылки на них стоят в подвале.
- `sitemap.xml`, `robots.txt` с секцией для Яндекса, гео-мета-теги (`geo.region`, `geo.position`,
  `ICBM`), манифест.
- Видео с YouTube грузится только по клику — страница остаётся быстрой.

## Добавить район

Допишите объект в `site.districts` — появится страница `/rayon/<slug>`, ссылка в подвале,
запись в sitemap и микроразметка с координатами. `inCity` и `ofCity` нужны для падежей.

Если страницы районов не нужны — удалите папку `src/app/rayon` и блок `districts` из конфига.

## Форма заявки

На странице её нет — заявки идут через звонок и Telegram. Готовый компонент остался в коде:
`src/components/lead-form.tsx` (валидация узбекского номера, защита от ботов, состояния загрузки
и ошибки) и серверный экшен `src/app/actions/lead.ts` (отправка в Telegram по
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, иначе запись в лог). Чтобы вернуть форму, вставьте
`<LeadForm source="price" />` в нужный блок. Если она не нужна — удалите оба файла и переменные
`TELEGRAM_*` из `.env.example`.
