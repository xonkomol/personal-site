# Adjaster.uz — лендинг услуг европротокола

Next.js 16 + Tailwind v4 + shadcn/ui. Весь контент и SEO лежат в одном файле —
`src/lib/site.config.ts`.

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Сайт поднимается на **http://localhost:4000** — порт задан в `package.json`
(`next dev --port 4000`, `next start --port 4000`). Корень `/` ведёт на `/ru`.

Сборка: `npm run build`, проверка кода: `npm run lint`.

## Структура страницы

1. **Хедер** — логотип, разделы, телефон и кнопка Telegram.
2. **Первый экран** — прописной заголовок с золотым акцентом, описание в стеклянной панели,
   крупный номер телефона, три кнопки действий и строка фактов (`site.contacts`).
3. **Преимущества** — три центрированные карточки с круглыми иконками (`site.advantages`).
4. **«Нужна срочная помощь?»** — яркая синяя плашка с телефоном (`src/components/sections/urgent.tsx`).
5. **Как оформить европротокол** — белая карточка: слева порядок действий,
   справа важные моменты (`site.howTo`).
6. **Услуги европротокола** — тёмно-синяя карточка: цена, что входит, что оплачивается отдельно,
   три карточки контактов (`site.pricing`).
7. **Консультация** — три золотые кнопки, блок «Дополнительные услуги» и карта Яндекса
   (`site.additional`, `site.address.map`).
8. **Футер** — четыре колонки: о компании, контакты, услуги, режим работы и районы.

## Два языка

- Русская версия — `/ru`, узбекская — `/uz`. Страницы районов: `/ru/rayon/mirabad`, `/uz/rayon/mirabad`.
  Корень `/` редиректит на `/ru` (настроено в `next.config.ts`).
- **Все тексты — в `src/lib/content.ts`**, по словарю на язык. Узбекский типизирован по русскому:
  забыли перевод — проект не соберётся.
- `src/lib/site.config.ts` — только то, что не зависит от языка: контакты, адрес, координаты, цены.
- `src/lib/i18n.ts` — список языков, префиксы путей, переключение, формат сумм (`сум` / `so'm`).
- Переключатель RU/UZ в шапке сохраняет текущую страницу. В мета-тегах проставлен hreflang,
  обе версии есть в sitemap.
- Добавить язык: впишите код в `locales`, добавьте словарь в `content.ts` — маршруты,
  sitemap и hreflang подхватятся сами.

## Что обязательно поменять

| Где | Что |
|---|---|
| `src/lib/site.config.ts` → `pricing.assessment` | **1 500 000 сум за оценку ущерба — плейсхолдер.** Поставьте свою цену. Цена европротокола (880 000 сум) согласована. |
| `src/lib/site.config.ts` → `contacts`, `address` | Телефоны, Telegram, email и адреса взяты из открытых источников — сверьте. |
| `.env.local` → `NEXT_PUBLIC_SITE_URL` | Боевой домен. От него зависят canonical, sitemap и микроразметка. |
| `src/lib/site.config.ts` → `address.coords` | **Координаты приблизительные.** Уточните в Яндекс Картах: правый клик по метке → «Что здесь?». Они идут в микроразметку `LocalBusiness`. |
| `src/lib/site.config.ts` → `address.map` | Виджет Яндекс Карт. Сейчас карточка организации `adjaster_uz/121345169480`. Запасной вариант по адресу — в комментарии рядом. |
| `.env.local` → `NEXT_PUBLIC_YM_ID` | Яндекс Метрика. Пусто — скрипт не подключается. |
| `src/lib/site.config.ts` → `seo.updatedAt` | Дата в `lastmod` карты сайта. Обновляйте при правке текстов: если дата меняется каждый день без изменений, поисковики перестают ей верить. |

Логотип лежит в `public/logo.png`. В подвале он выводится белым через CSS-фильтр.
Цвета — в `src/app/globals.css`, блок `:root`: `--tile` (синий логотипа), `--tile-deep` (тёмная база),
`--accent` (оранжевый для кнопок действия).

## Движение

Всё на CSS, без библиотек анимации и без JavaScript:

- `.brand-gradient` и `.brand-gradient-soft` — тёмно-синий градиент с подсветкой цветом логотипа.
  Используются в первом экране, карточке вызова и подвале.
- `.enter` + `.enter-1 … .enter-5` — одна срежиссированная сцена при загрузке первого экрана:
  бейдж, заголовок, описание, кнопки и строка районов проявляются по очереди.
- `.pulse-call` — мягкий ореол вокруг кнопки вызова. Единственный повторяющийся эффект на сайте.
- `.lift` — подъём карточки или кнопки при наведении.
- `[data-reveal-item]` — появление блоков при прокрутке через `animation-timeline: view()`.
  Браузеры без поддержки показывают содержимое сразу, без анимации.
- Всё это выключается при системной настройке «уменьшить движение»
  (`prefers-reduced-motion: reduce`).

## Скорость

- Все страницы пререндерятся статически: сервер отдаёт готовый HTML, React догружается следом.
- Шрифты — через `next/font`, файлы лежат на своём домене, запросов к Google Fonts нет.
- Сторонних скриптов на странице нет. Яндекс Метрика подключается только если задан
  `NEXT_PUBLIC_YM_ID`, и грузится после отрисовки (`strategy="afterInteractive"`).
- Карта Яндекса грузится отложенно (`loading="lazy"`) — единственный внешний iframe на странице.
- `@vercel/speed-insights` подключён в `src/app/layout.tsx`. Он не ускоряет сайт сам по себе —
  он собирает Core Web Vitals (LCP, CLS, INP, TTFB) у реальных посетителей, чтобы видеть,
  что чинить. Данные появляются во вкладке Speed Insights проекта **после деплоя на Vercel**;
  локально компонент работает в отладочном режиме и ничего не отправляет.

## Что сделано для поиска

- Уникальные title и description на каждой странице, canonical, Open Graph, генерируемая картинка
  `/opengraph-image` с телефоном.
- **Ключевые слова** — `src/lib/keywords.ts`, 45 согласованных запросов: оформление ДТП,
  географические, европротокол на узбекской латинице и кириллице. Один список на все страницы
  и обе языковые версии.
- Микроразметка одним `@graph`: `LocalBusiness` + `AutomotiveBusiness` с адресом, координатами,
  круглосуточным графиком и телефоном; `Service` с ценой; `HowTo` с восемью шагами инструкции;
  `BreadcrumbList`.
- **Страницы районов** `/[locale]/rayon/[district]` — по одной на каждый район из `site.districts`,
  со своим H1, title, description, уникальным текстом, ориентирами и координатами.
  Закрывают запросы вида «европротокол + район». Ссылки на них стоят в подвале.
- **`/robots.txt`** (`src/app/robots.ts`) — открыт весь сайт, отдельная секция для Яндекса
  с директивой `Host`, закрыты только агрессивные сканеры (Ahrefs, Semrush, MJ12, DotBot, Petal).
  `/_next/static` намеренно не закрыт: без CSS и JS поисковик не отрисует страницу.
- **`/sitemap.xml`** (`src/app/sitemap.ts`) — главная и все страницы районов, собирается
  из `site.districts`: добавили район — он сразу в карте сайта. Оба адреса берутся из
  `NEXT_PUBLIC_SITE_URL`, так что после смены домена править ничего не нужно.
- Гео-мета-теги (`geo.region`, `geo.position`, `ICBM`), манифест.
- Единственный внешний iframe на странице — карта Яндекса, и та грузится отложенно.

## Как отдать сайт на индексацию

1. Укажите боевой домен в `NEXT_PUBLIC_SITE_URL` и задеплойте.
2. Проверьте, что открываются `https://ваш-домен/robots.txt` и `https://ваш-домен/sitemap.xml`.
3. Добавьте сайт в [Яндекс Вебмастер](https://webmaster.yandex.ru) и
   [Google Search Console](https://search.google.com/search-console), подтвердите права —
   коды вставляются через `NEXT_PUBLIC_YANDEX_VERIFICATION` и `NEXT_PUBLIC_GOOGLE_VERIFICATION`.
4. В обоих сервисах добавьте адрес карты сайта и отправьте главную на переобход.
5. Заведите карточку организации в Яндекс Бизнесе и Google Business Profile — адрес, телефон
   и график в них должны совпадать с теми, что в `site.config.ts`: поиск сверяет эти данные.

## Добавить район

1. Добавьте `{ slug, coords }` в `site.districts` (`src/lib/site.config.ts`).
2. Добавьте блок с тем же `slug` в `districts` **обоих** словарей `src/lib/content.ts`:
   `name`, `short`, `inCity`, `ofCity`, `landmarks`, `intro`. Поля падежей нужны, чтобы
   заголовки читались по-человечески на обоих языках.

Страницы `/ru/rayon/<slug>` и `/uz/rayon/<slug>`, ссылки в подвале, записи в sitemap
и микроразметка с координатами появятся сами.

Если страницы районов не нужны — удалите папку `src/app/[locale]/rayon` и блок `districts`.
